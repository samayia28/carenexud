# CareNexus React Frontend

A responsive React + Vite frontend inspired by the supplied CareNexus reference design.

## Included pages
- Home
- About Us
- Diseases + search/filter
- Disease detail pages
- Mental Health + topic detail pages
- Donate form (demo interaction; no real payment)
- Contact form (demo interaction; no backend)
- Login / Sign Up (demo navigation)
- Dashboard
- Helplines
- Health Tips
- Profile
- Settings

## Run locally

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Notes
- All routing uses React Router.
- Disease content is stored in `src/data/data.js`.
- Styling is in `src/styles.css`.
- Forms are frontend-only demonstrations until a backend/API is connected.
- The emergency/health information is educational and should not replace professional medical advice.
